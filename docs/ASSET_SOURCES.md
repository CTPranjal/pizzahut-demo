# Asset sources

Every image in `ios/assets-source/img/` was downloaded from a public URL that needs no login. `ios/scripts/build_assets.py` copies the same files into the iOS asset catalog.

Product, banner, deal and category images come from the Pizza Hut Malaysia storefront CDN (`cdn.fynd.com`). Where an image was resized, it was fetched through the same CDN's resize endpoint (`cdn.pixelbin.io`, width 600 to 1600 px, JPEG). The source URL below is the original, unresized file. Category tiles were then downscaled locally to 480 px wide.

Store outlet names and coordinates come from OpenStreetMap (see the Stores section).
